Как добавить новый сложный тип (user) данных (пример) - 1. Создать POJO в model который описывает ваш обьект
2. Создать реализацию интерфейса UserTypeInterface который будет переопределять существующие методы
3. Добавить ваш обьект в Фабрику типов (UserFactory.java)

Для сортировок и т.д действия идентичны
