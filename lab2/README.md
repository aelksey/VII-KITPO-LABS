Вот пошаговая инструкция, как правильно импортировать лабораторный проект на Scala 2 в среду разработки IntelliJ IDEA и успешно запустить графический интерфейс.
------------------------------
## Шаг 1: Подготовка (Проверка плагина)
Перед импортом убедитесь, что в IntelliJ IDEA установлен плагин для поддержки Scala.

   1. Откройте IntelliJ IDEA.
   2. В главном меню перейдите в Settings (Настройки) -> Plugins (Плагины).
   3. В строке поиска введите Scala. Если плагин не установлен, нажмите Install и перезапустите среду разработки.

------------------------------
## Шаг 2: Импорт проекта в IntelliJ IDEA
В зависимости от того, как настроена сборка вашей лабораторной (через стандартный инструмент sbt или как обычный Java/Scala проект со встроенными библиотеками), выберите подходящий путь:
## Вариант А: Если проект использует сборщик SBT (в корне есть файл build.sbt) — Рекомендуемый

   1. Нажмите File -> Open (или Open or Import на приветственном экране).
   2. Выберите папку вашего проекта (в которой лежит файл build.sbt) и нажмите OK.
   3. В появившемся окне выберите Open as Project.
   4. В правом нижнем углу начнется процесс импорта и скачивания зависимостей (SBT-фоновые задачи). Подождите несколько минут, пока проект полностью проиндексируется, а индикаторы загрузки исчезнут.

## Вариант Б: Если это обычный проект без файлов сборки (только папка src)

   1. Нажмите File -> New -> Project from Existing Sources...
   2. Выберите корневую папку вашего проекта и нажмите OK.
   3. Выберите пункт Import project from external model -> выберите Bloop (так как ваши логи были из bloop) или Eclipse/Flash/Maven в зависимости от конфигурации. Если конфигураций нет, выберите Create project from existing sources и нажимайте Next до завершения.
   4. После открытия проекта нажмите File -> Project Structure -> Global Libraries. Нажмите на +, выберите Scala SDK, укажите версию Scala 2.13.x и привяжите её к вашему модулю.

------------------------------
## Шаг 3: Настройка SDK и компилятора
Чтобы код не подсвечивался красным:

   1. Перейдите в File -> Project Structure... (или нажмите Ctrl + Alt + Shift + S).
   2. Вкладка Project: убедитесь, что в поле SDK выбрана корректная версия Java (рекомендуется JDK 17 или JDK 11, так как в Java-коде использовались современные методы фабрик и RandomGenerator).
   3. Вкладка Modules: проверьте, что папка src/main/scala (и src/main/java, если она осталась) подсвечены синим цветом (как Source Folders). Если это не так, кликните по папке правой кнопкой мыши и выберите Mark as -> Sources.

------------------------------
## Шаг 4: Запуск GUI приложения
Так как мы переписали главный класс на стандартный для scala.swing синглтон, запуск выполняется очень просто:

   1. В дереве проекта (слева) разверните папки: src -> main -> scala -> gui.
   2. Найдите файл Main.scala (тот самый, который содержит object Main extends SimpleSwingApplication).
   3. Нажмите правой кнопкой мыши в любом месте внутри этого файла или по самому файлу в дереве проводника.
   4. В контекстном меню выберите пункт Run 'Main' (с зеленым треугольником).

------------------------------
## Что делать, если возникли проблемы при запуске?

* Ошибка "Cannot find symbol/class": Выполните очистку и пересборку проекта. В верхнем меню выберите Build -> Rebuild Project.
* Приложение запускается, но окно GUI сразу закрывается: Проверьте класс Main.scala. Он должен строго наследоваться от SimpleSwingApplication, а весь код инициализации фрейма должен находиться внутри метода override def top: MainFrame = { ... }.
* Красный код на строках с scala.swing: Это значит, что библиотека Swing для Scala не подключена. Если вы используете SBT, добавьте в ваш файл build.sbt строку:

libraryDependencies += "org.scala-lang.modules" %% "scala-swing" % "3.0.0"

(Версию 3.0.0 можно скорректировать под вашу версию Scala 2.13).
