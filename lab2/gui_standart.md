Напиши код для графического интерфейса (GUI) на языке Scala с использованием библиотеки `scala.swing` (или стандартного `javax.swing`, если это необходимо для совместимости), строго соблюдая следующие требования к архитектуре, синтаксису и стандартам оформления:

1. Версия и базовый стиль: Используй исключительно классический стандарт Scala 2. Полностью исключи синтаксис Scala 3, основанный на отступах (никаких значимых отступов, никаких ключевых слов 'then' в ветвлениях или 'do' в циклах).
2. Обязательные фигурные скобки: После любого управляющего оператора (if, else, catch, while, for, foreach) или обработчика событий (reactions, listenTo) ВСЕГДА должен следовать явный блок кода, обернутый в фигурные скобки {}, даже если внутри всего одна строка. Примеры: 
   - if (условие) { действие }
   - listenTo(button)
   - reactions += { case ButtonClicked(b) => { действие } }
3. Обязательные круглые скобки: Все условия в управляющих конструкциях (if, while) должны быть строго обернуты в круглые скобки ().
4. Чистота кода (без двоеточий в логике): Полностью исключи использование двоеточий ':' во всей логике программы (включая case-конструкции сопоставления шаблонов match). Двоеточия разрешены ИСКЛЮЧИТЕЛЬНО для стандартного объявления типов переменных и методов (например, val button: Button = new Button).
5. Наследование от SimpleSwingApplication: Главное окно приложения должно наследоваться от класса `SimpleSwingApplication`. Метод `top` должен возвращать объект `MainFrame`. Каждое свойство (title, contents) внутри `MainFrame` должно настраиваться явно.
6. Обработка событий (Events): Для подписки на события кнопок, текстовых полей или меню используй конструкцию `listenTo(...)`. Обработку событий внутри `reactions +=` оформляй через сопоставление шаблонов (match/case), где правая часть `=>` обязательно оборачивается в фигурные скобки `{}`.
7. Компоновка (Layout): Используй стандартные контейнеры компоновки Scala Swing (BoxPanel, GridBagPanel, BorderPanel, FlowPanel) с явным указанием их параметров и содержимого внутри фигурных скобок `{}`.
8. Разрешение перегрузок методов (Типизация): Если методы Java-компонентов или слушателей возвращают значения (например, boolean), а Scala ожидает Unit, явно завершай тело лямбда-выражения или блока возвратом пустого значения `()`.
