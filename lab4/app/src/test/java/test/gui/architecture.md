# Архитектурное описание пакета `test.gui`

**Назначение пакета:** Интеграционное функциональное тестирование графического интерфейса пользователя (GUI) приложения с использованием робота-манипулятора библиотеки `AssertJ Swing`. Пакет эмулирует интерактивное взаимодействие пользователя с экранными формами (клики по кнопкам, ввод текстовых строк, изменение значений счетчиков) и проверяет реакцию внутренних СД и текстовых полей логирования.

### Архитектурные принципы и методология UI-тестирования
* **Изоляция в потоке обработки событий (EDT Thread Safety):**
  Согласно спецификации Java Swing, любые операции создания и модификации видимых окон выполняются строго в системном потоке *Event Dispatch Thread*. Архитектура тестов использует фабричный мост `GuiActionRunner.execute()` для корректного и безопасного разворачивания главного окна приложения (`ListApplicationPanel`) внутри изолированной тестовой сессии.
* **Адресация компонентов по системным именам (`Component Name Binding`):**
  Робот-манипулятор `FrameFixture` осуществляет поиск интерактивных компонентов не по их абстрактному геометрическому расположению на экране, а по уникальным программным идентификаторам `setName()`, зафиксированным в исходном коде (`value`, `logicalIndex`, `blockCapacity`, `output`). Это обеспечивает устойчивость тестов к изменениям экранной разметки.
* **Полнота функциональных приемочных сценариев:**
  Тестовый набор реализует сквозную проверку бизнес-логики приложения (End-to-End Test):
  * *Модификация данных:* Робот осуществляет ввод значений, имитирует клик по кнопке «Вставить в начало» и контролирует изменение счетчиков элементов.
  * *Изменение конфигурации памяти:* Тест модифицирует параметры `JSpinner` вместимости нод, запускает событие «Перегруппировать» и валидирует процесс внутренней перестройки блоков СД.
  * *Выполнение алгоритмов:* Эмулируется вызов генератора случайных наборов данных с последующим триггером inplace-сортировки и проверкой итоговых логов консоли.

### Структура и компоненты пакета
Пакет расположен в каталоге `src/test/java/test/gui/` и включает в себя:
* **`ApplicationGuiTest.java`** — основной управляющий компонент тестирования, координирующий инициализацию фрейма, действия виртуального манипулятора над панелями кнопок (`ListOperationsPanel`, `AlgorithmsPanel`, `BlockSettingsPanel`, `RandomListPanel`) и финальную очистку ресурсов операционной системы через метод `window.cleanUp()`.
